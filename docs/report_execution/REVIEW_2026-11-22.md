## Reproduction commands

Run from repository root with the existing project venv and MiKTeX installation.

~~~powershell
.\.venv\Scripts\python.exe -B report/dacn/generate_assets.py
.\.venv\Scripts\python.exe -B report/dacn/generate_case.py
.\scripts\build-hcmut-template.ps1 -Report
.\.venv\Scripts\python.exe -B scripts/inspect_pdf.py build/latex/dacn/main.pdf --output-dir build/latex/dacn/review-final
~~~

Use the existing `-Manual` switch if an interrupted run leaves an incomplete BibTeX auxiliary file. Both TikZ wrappers are compiled into `build/latex/dacn/graphics` before the main document.
