\begin{frame}{Failure Analysis: Key Findings}

\small

\begin{block}{1. Indirect Query Formulation}
    Query đôi khi chưa xác định rõ entity hoặc thông tin cần tìm,
    khiến model truy vấn lệch hướng.
\end{block}

\vspace{0.15cm}

\begin{block}{2. Insufficient Evidence Handling}
    Khi evidence không đủ, model vẫn tiếp tục suy luận và đưa ra
    câu trả lời thiếu căn cứ thay vì nhận diện giới hạn thông tin.
\end{block}

\vspace{0.2cm}

\textbf{Key Takeaway:}

\textit{Reliable reasoning requires both effective query formulation
and proper evidence sufficiency assessment.}

\end{frame}
